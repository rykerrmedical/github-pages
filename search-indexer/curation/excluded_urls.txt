# Rykerr Medical search — content exclusions
#
# One URL (or URL prefix) per line. Anything listed here is skipped
# entirely during indexing — never crawled, never chunked, never
# searchable — even though it's still live and linked on the site.
#
# Use this for superseded drafts, old versions of a document you've
# since replaced, or anything else you don't want search surfacing.
# There's no "prefer new over old" scoring here on purpose — this is a
# hard exclude, which is the most reliable way to guarantee an old
# version never gets cited by accident.
#
# Two forms:
#   An exact URL        -- excludes just that one page or PDF.
#   A URL ending in *    -- excludes everything under that prefix
#                           (e.g. an entire folder of old drafts).
#
# Blank lines and lines starting with # are ignored. Edit this file any
# time — it's picked up fresh on the next index rebuild, no code changes
# needed.
#
# Examples (commented out — replace with your actual URLs):
# https://rykerrmedical.com/downloads/vent-book-draft-v2.pdf
# https://rykerrmedical.com/old-drafts/*
